# react-tailwind/ui-primitive@7924

Accessible Tailwind primitive using CVA for variants, Radix Slot for composition, and the shared class merger.

- Change identifiers, variants, sizes, props, and loading content.
- Preserve ref forwarding, typed variants, conflict-safe class merging, and disabled/loading semantics.
- Keep domain behavior, remote data, and page-specific rules outside `components/ui`.
