01 / What is ArchBase

Conventions that agents can inspect.

Instead of relying only on prompts such as “follow the project pattern” or “create this file like the others”, define concrete structural references that an agent can inspect and reuse.

{ }

Patterns

Define how a type of code is structured.

↳

Rules

Define where code belongs and which relationships are allowed.

[ ]

Scopes

Define which pattern applies to a specific part of a project.

⊞

Registries

Distribute reusable patterns and architecture rules.

⇄

MCP

Expose that context directly to compatible AI agents.

“They understand the task, but not always the exact way your project expects that code to be organized.”

Turn implicit conventions into something that can be:

  • versioned
  • inspected
  • reused
  • customized locally
  • exported to coding agents
  • resolved by project path
  • exposed through MCP

02 / Quick start

Three steps. One shared reference.

Give your next coding session an architecture to work from.

01

Install ArchBase

The official installer detects the architecture, verifies the release checksum, and configures the user PATH.

curl -fsSL https://archbase.caetanodev.com/install.sh | sh
02

Add a pattern

ArchBase creates a local .archbase scope and stores the validated pattern bundle.

arc add next/page@1234 .
03

Inspect the pattern

Developers and agents can inspect the canonical structure before generating new code.

arc resolve src/pages/Home.tsx
arc inspect next/page@1234

03 / AI agents

One canonical source. Every agent.

ArchBase rules are agent-neutral. Export the same canonical architecture rule for the tools you already use.

↗

Cursor

arc rules add architecture/next-modular@1 --format cursor

→ .cursor/rules/

⌘

GitHub Copilot

arc rules add architecture/next-modular@1 --format copilot

→ .github/instructions/

A

AGENTS.md

arc rules add architecture/next-modular@1 --format agents --merge

→ merges without touching unrelated content

05 / Philosophy

Explicit by design.

  1. Architecture should be explicit.
  2. Patterns should be reusable.
  3. Local conventions should remain customizable.
  4. AI agents should inspect context instead of guessing it.
  5. Generated instructions should come from one canonical source.
  6. Existing project files should be treated safely.

The goal is to make developer decisions easier to communicate — to humans and to coding agents.

Define the architecture once.
Let humans and agents follow it.
